# 🎙️ Urdu AI Voice Over Generator

AI-powered Urdu Text-to-Speech application built with **Python, Streamlit and Microsoft Edge TTS**.

This project converts Urdu text into natural AI voice and generates MP3 audio files.

## ✨ Features

- 🎙️ Urdu Male & Female AI Voice
- 📝 Text to Speech Generation
- 🎚️ Speed Control
- 🎚️ Pitch Control
- 📥 MP3 Download
- 🌙 Modern Streamlit Interface

---

## 🛠️ Technologies

- Python
- Streamlit
- Edge-TTS
- AsyncIO
- Google Colab

---

## ▶️ How to Use

1. Open the Google Colab notebook.
2. Run all cells step by step.
3. Install required libraries.
4. Start Streamlit application.
5. Open the generated public URL.
6. Enter Urdu text and generate AI voice.
